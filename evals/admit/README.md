# Admit: may this item start without an operator?

A shadow measurement. Nothing in the pack acts on it. It asks whether an agent, given a
project's admit policy, makes the same call an operator would have made: start this item
automatically after triage, or ask first.

- `policy-archon.md`: a draft admit policy for Archon, written for the measurement.
- `prompt.md`: what the judging agent is given.
- `backtest-<date>.md`: one run against past items, with how the labels were made.

The label for a past item is what happened to it, not what anyone thought beforehand:
an item that went from intake to merged with no ruling by an operator and no overrule of
a stage "could have been auto"; one that needed a ruling or an overrule "should have asked".
