# Triage eval

28 community issues from the Archon repository, each stored as an item file in `items/`: the title, the body and the discussion as they stood on 2026-11-12. Labels are left out, because some of them were written by an earlier triage.

`key.json` holds what the maintainer decided for each on 2026-11-09, in his own short words (`build`, `close`, `recipe`, `park`, ...) with his note where he left one. It also records where he overrode the recommendation he was given, since those are the hard cases, and what the old SDLC pack's triage answered.

Triage is scored on whether it lands where the maintainer did, not on whether it matches any earlier run. The old pack scored 17 agree, 8 partly, 3 disagree, at about 600k input tokens and 94 seconds per item.
