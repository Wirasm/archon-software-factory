# Console: the run page's Log / Graph / Artifacts tab and node filter are not in the URL, so Back skips them and a tab cannot be linked

Filed by robertmeisner.

## Problem

On a run's page (`/console/p/:projectId/r/:runId`), switching between **Log**, **Graph** and **Artifacts**, or picking a node in the filter, does not change the URL. As a result:

- The browser's Back button skips every tab change and leaves the run page instead of returning to the previous tab.
- A link to a run cannot open a given tab or node (for example the graph of one node), so it cannot be shared or bookmarked.
- After a reload, **Artifacts** is not restored: the page opens on Log.

## Steps to reproduce

1. Open any run in the console.
2. Click **Graph**, then **Artifacts**.
3. Press the browser's Back button: the console leaves the run page instead of returning to **Graph**.
4. With **Artifacts** selected, reload: the page opens on **Log**.

## Root cause

`packages/web/src/experiments/console/routes/RunDetailPage.tsx` keeps the tab and the node filter as component state persisted to `localStorage` (`TOGGLE_KEYS.view` and `TOGGLE_KEYS.node`, lines 51-56; `useState(() => readView())` and `useState(() => readNodeFilter())`, lines 351-352; `setViewPersist`, line 489). Nothing writes them to the URL, so the history has no entry for them. `readView()` (line 78) only returns `'graph'` or `'log'`, so a stored `'artifacts'` falls back to `'log'`.

## Proposal

Carry both in the URL's query string with react-router's `useSearchParams`, as `MetricsPage` and `RunsPage` already do: `?view=graph|log|artifacts&node=<node-id>`.

- A tab or node change pushes a history entry, so Back returns to the previous tab; the initial normalisation (no `view` in the URL) replaces instead of pushing, so it adds no entry.
- When the URL has no `view`, fall back to the stored preference as today, so the remembered default keeps working; `readView` accepts `'artifacts'` too.
- Links that should open a tab (for example from a node in the run list) can then pass `?view=graph&node=...`.

A test can render the page in a `MemoryRouter`, switch tabs, go back with `navigate(-1)` and assert the previous tab is shown, and assert that `?view=artifacts` opens Artifacts.

Observed on Archon 0.13.2; the code above is from `main` at 442c90f.
