# A runtime: uv script node joins the target repository's uv project and writes .venv and uv.lock into the checkout

## Problem

A `script:` node with `runtime: uv` runs `uv run [--with dep ...] python -c <code>` or `uv run [--with dep ...] <path>` (`packages/workflows/src/script-invocation.ts`) with the run's checkout as its working directory. When that checkout is a Python project (it has a `pyproject.toml`), `uv run` treats the script as part of that project: it creates `.venv` in the checkout, resolves and installs the project's own dependencies, writes `uv.lock`, and applies the project's uv settings.

The bun side of the same function already guards its boundary: it passes `--no-env-file`, with the comment "Preserve Archon's environment boundary when Bun runs in a repository with .env". The uv side has no equivalent.

## Why

- The node changes the checkout it runs in. `uv.lock` is a new untracked file, so a later node that commits the worktree can commit it.
- The node can fail for reasons in the target's project, not in the script: an unresolvable dependency, or a `requires-python` the machine does not have.
- The node's dependencies depend on which repository it runs against, not on its own `deps:`.

## Desired outcome

A `runtime: uv` script node runs outside the target repository's uv project, the same way a bun script node runs without the repository's `.env`.

## Acceptance

- [ ] An inline `runtime: uv` script node run against a checkout that has a `pyproject.toml` leaves no `.venv` or `uv.lock` behind.
- [ ] Its `deps:` still install.

## Evidence

### Reproduction

The command the node builds, run in a fresh repository whose only file is a minimal `pyproject.toml` (`[project]` with `name`, `version`, `requires-python = ">=3.8"`, `dependencies = []`):

```
$ uv run python -c 'print("hello from the script node")'
Using CPython 3.14.10
Creating virtual environment at: .venv
hello from the script node
$ git status --short
?? uv.lock
```

### Environment

- Archon version or commit: `dev` at `40e531e7b` (`script-invocation.ts`); uv 0.13.7
- Platform or adapter: CLI
- Database: SQLite
- OS: Linux

- Related issues or PRs: #999 (script nodes with bun and uv runtimes)

- Solution steering: Hint — `uv run --no-project` keeps `--with` working and skips project discovery.
