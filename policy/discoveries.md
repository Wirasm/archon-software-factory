# Discoveries policy: the pack's default

A project that names no policy of its own is held to its own guidance: the agent guidance file at its root and the documents that file points to.

What earns a filed item: something checked against the code that a maintainer would want built or decided, and that no open item covers. A real defect in behaviour that someone would meet comes before cleanup, and a thing that only might matter is held, not filed.
