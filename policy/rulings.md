# Rulings: the pack's default

This file records no rulings. It says where a project keeps its own.

A ruling is an answer the project's maintainers have already given to a question a stage would otherwise stop on: whether a kind of thing gets a test, whether a kind of change needs a maintainer, what is out of scope. A project keeps them in a file named `rulings.md` beside its policy files, one entry per ruling: the question it settles, the answer, and the project document it rests on when there is one.

Every stage reads the project's `rulings.md`, when there is one, before it leaves an ask. A question a ruling answers is settled: cite the ruling and go on. A ruling about one work item is not written here; it is recorded on the item.
