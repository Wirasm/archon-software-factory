# Review policy: the pack's default

A project that names no policy of its own is held to its own guidance: the agent guidance file at its root and the documents that file points to.

- The defect is usually not in the lines that changed. It is in a counterpart the change now disagrees with: another member of the same set, another way into the same thing, the reader of what it writes, the path that rebuilds what it builds. For each place the change touches, find its counterparts and check them. A finding names both sides.
- A passing check is evidence only once you know it fails without the change.
